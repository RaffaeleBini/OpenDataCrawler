Guía del Portal DATAlife

Cómo definir el alcance (país y sector), buscar, explorar, descargar y consultar por API los datos abiertos del catálogo. Nació centrado en Galicia y en las cuatro cadenas de valor de DATAlife (Agro-Mar-Alimentación, Forestal-Madera, Salud-Cuidados y Biotecnología), y ahora cubre cualquier país y sector: esas cuatro siguen ahí, como una opción más.

Antes de empezar: el portal está todavía en fase de pruebas internas. Las capturas de esta guía son un modelo del funcionamiento real; cuando publiquemos la dirección definitiva, actualizaremos aquí el enlace.

Paso 1

Acceder al portal

El catálogo se abre en el navegador, sin necesidad de instalar nada.

En el entorno de pruebas actual, la dirección es https://localhost:8443 y solo es accesible desde el equipo donde corre la plataforma. El navegador mostrará un aviso de seguridad porque el certificado es de desarrollo; puedes continuar con confianza en este entorno.

No necesitas una cuenta para buscar, ver o descargar datos: la cuenta solo hace falta para publicar datasets propios o generar una clave de acceso a la API (paso siete).

Paso 2

Definir el alcance: país y sector

La propia portada empieza por aquí: en el sitio donde otros portales ponen un buscador, este tiene un filtro para acotar por país o región y por sector antes de mirar nada.

Elige un país/región y un sector (o deja "Todos" en cualquiera de los dos) y pulsa "Explorar catálogos". Verás un directorio de catálogos de datos abiertos que encajan con tu selección — no son datasets sueltos, son fuentes completas, cada una con una etiqueta:

  • Ya conectado: sus datos ya están dentro de este portal; búscalos con el paso tres o entra directamente por su cadena de valor u organización (paso cuatro).
  • Pendiente de conectar: es una fuente real y verificada, pero todavía no se ha traído al portal. Si te interesa, coméntaselo a la persona administradora (paso ocho).

Este directorio se amplía con el tiempo: hoy cubre España (incluida Galicia) y varios países y organismos internacionales (por ejemplo, Reino Unido o la FAO), pero no pretende ser exhaustivo desde el primer día.

Paso 3

Buscar datos

La barra de búsqueda superior admite texto libre; los filtros de la izquierda acotan por cadena de valor, formato, etiqueta o entidad publicadora.

Escribe una palabra clave (por ejemplo, incendios o acuicultura) y pulsa Intro. Combina varios filtros a la vez para acotar: quedará, por ejemplo, solo lo que sea de la cadena Forestal-Madera y esté en formato CSV.

Paso 4

Explorar por cadena de valor

Esto es específico de la parte gallega del catálogo: cada cadena de valor de DATAlife es una organización, con todos sus datasets agrupados. Para el resto de países y sectores, usa el filtro del paso dos.

Agro-Mar-Alimentación Forestal-Madera Salud-Cuidados Biotecnología

Desde la página de inicio, elige "Organizaciones" y selecciona la tuya. Dentro, puedes seguir filtrando por palabra clave, igual que en la búsqueda general.

Paso 5

Abrir un dataset

La página de cada conjunto de datos siempre tiene la misma estructura, así que una vez que la conoces, te orientas en cualquiera.

Paso 6

Descargar un recurso

Cada recurso indica su formato (CSV, JSON, GeoJSON, Parquet…) antes de descargarlo.

  1. Abre el dataset que te interese.
  2. En la lista de "Recursos", localiza el archivo por su nombre y formato.
  3. Pulsa Descargar: el archivo se guarda directamente, sin pasos intermedios.

Si el dataset procede de una fuente externa que solo indexamos (no alojamos), el botón te lleva directamente al archivo en su portal de origen.

Paso 7

Usar la API

Toda búsqueda y toda descarga que haces a mano en el portal también se puede pedir por programa, con la misma interfaz de programación de aplicaciones (API) que usa el propio catálogo.

Buscar datasets por palabra clave y cadena de valor:

# cadena de valor "forestal-madera", palabra clave "incendios" curl "https://localhost:8443/api/3/action/package_search?q=incendios&fq=organization:forestal-madera"

Consultar un dataset concreto y obtener las URL directas de sus archivos:

# sustituye el nombre por el del dataset que te interese curl "https://localhost:8443/api/3/action/package_show?id=incendios-forestais-galicia"

Lo mismo desde JavaScript, por ejemplo dentro de tu propia aplicación:

// devuelve los datasets de Salud-Cuidados que mencionan "envellecemento" const resp = await fetch( "https://localhost:8443/api/3/action/package_search?q=envellecemento&fq=organization:salud-cuidados" ); const datos = await resp.json(); console.log(datos.result.results);

Paso 8 Solo administradores del sistema

Añadir una fuente de datos nueva

Si formas parte del equipo técnico y tienes permisos de administración, puedes dar de alta una fuente de recolección nueva directamente desde el portal, sin tocar código. Normalmente parte de una fuente marcada como "Pendiente de conectar" en el directorio del paso dos.

  1. Abre el menú de tu cuenta (arriba a la derecha). Si eres administrador del sistema, verás un enlace "Fuentes de datos" que no aparece para el resto de personas usuarias.
  2. Pulsa "Fuentes de datos": te lleva directo al formulario.
  3. Rellena los campos: nombre, título, la URL de la API o el catálogo de origen, el tipo de fuente, la cadena de valor a la que pertenece y la frecuencia de actualización.
  4. Guarda. La fuente queda dada de alta; el equipo técnico ejecuta la primera recolección para traer los datos por primera vez.

Preguntas frecuentes

Dudas habituales

¿Necesito permiso para usar estos datos?

Cada dataset muestra su licencia. La mayoría son de reutilización abierta, pero conviene comprobarlo antes de un uso comercial, sobre todo en datasets que solo indexamos desde otra fuente.

¿Por qué un enlace de descarga me lleva a otra web?

Porque ese dataset no lo alojamos nosotros: indexamos su ficha y enlazamos al portal original para no duplicar el archivo.

¿Puedo pedir que se incorpore un dataset que no está?

Sí. Escríbenos con el enlace o la fuente y lo evaluamos para incorporarlo en las próximas fases.

¿Hay límite de peticiones a la API?

Para uso puntual, no. Si vas a hacer muchas peticiones seguidas, usa una clave de API (paso siete) para evitar bloqueos por exceso de tráfico.

¿Por qué no veo el enlace "Fuentes de datos" en mi cuenta?

Ese enlace y el formulario del paso ocho solo están disponibles para administradores del sistema. Si necesitas añadir una fuente y no tienes ese permiso, contacta con el equipo técnico.

¿Qué diferencia hay entre el filtro de país/sector de la portada y "Explorar por cadena de valor"?

El filtro de la portada (paso dos) recorre un directorio de catálogos de cualquier país y sector, conectados o no. "Explorar por cadena de valor" (paso cuatro) es específico de la parte gallega: te lleva directo a los datasets que ya están dentro del portal para uno de los cuatro sectores de DATAlife.

Glosario

API
Interfaz de programación de aplicaciones: forma de pedir datos por programa, sin usar el navegador.
CKAN
Software libre de catálogo de datos abiertos que da soporte a este portal.
CSV / JSON / GeoJSON
Formatos de archivo habituales para datos tabulares o geográficos.
Organización (en CKAN)
La agrupación que usamos para representar cada cadena de valor de DATAlife.
Recurso
Cada archivo concreto dentro de un dataset (por ejemplo, un CSV y un GeoJSON del mismo conjunto).
Fuente de recolección
La configuración que le dice al portal dónde y cómo recoger los datos de un organismo externo (paso ocho).
DCAT
Data Catalog Vocabulary: formato estándar en el que muchos organismos publican su catálogo de datos.
Directorio de catálogos
Listado curado de fuentes de datos abiertos por país/región y sector, con las que ya están conectadas marcadas como tal (paso dos).
